# Finance Hub · 金融信息聚合平台

基于 **Node 原生 http（零 npm 依赖）** 的本地金融信息聚合平台，数据源为 [westock CLI](https://github.com/)（腾讯自选股数据接口），全部为真实数据。浅色商务风单页前端（Chart.js 本地内置），遵循 A 股「涨红跌绿」配色惯例。

## 功能模块

| 模块 | 能力 |
|---|---|
| **市场总览** | 指数行情、13 维市场画像雷达、涨跌分布、行业榜、新股动态 |
| **新股消息** | 沪深 / 港股 / 美股三市场新股日历，阶段自动归类，订阅推送（站内通知中心 + 定时巡检） |
| **新股资讯** | 在发新股相关新闻聚合（标题 / 时间 / 摘要），**逐条附带上市表现判定（暴涨 / 破发）**，热度榜，点击查看个股全部资讯 |
| **股票列表** | 7 维分类浏览：宽基指数 / 申万一二级 / 热门概念 / 沪深港通 / 热门榜单 / 港股（模拟数据占位）；点击直达财报 |
| **推荐榜单** | 12 种量化榜单 × 50 只，每只附可溯源推荐理由与风险提示 |
| **AI 选股** | 三档激进度（保守 / 稳健 / 进取）差异化推荐方案；持仓持续判读卖出信号（S1–S7 规则）；自选与交易记录管理；每天 08:30 自动分析 |
| **全球行情** | 贵金属（伦敦金 / 银现货实时价 + 境内 ETF 代理走势）、外汇（10 货币对汇率 / 日 K / 分时 / 波动统计） |
| **国际形势** | 全球市场快照、多源国际要闻聚合、规则化主题影响分析（逐条引用真实新闻标题） |
| **财报整理** | 三大报表结构化归集、多期趋势、多公司对比、披露日历、主营业务与收入结构 |
| **市场分析** | 板块轮动四榜、热搜、市场体检报告一键生成并导出 HTML |
| **附录** | 128 条术语与评分依据（三级编号、可点击互引、深链直达）、港股 / A 股交易指南 |

## 启动

```bat
:: 需要先安装 westock CLI（腾讯自选股数据接口）
启动平台.bat
:: 或
node server.js --port=8787
```

浏览器访问 <http://127.0.0.1:8787>。持仓、交易、通知等用户数据持久化在 `data\`（自动创建，不入库）。

## 新股暴涨 / 破发判定

「新股资讯」的每条消息都会自动附上该股**上市后的价格表现**判定，结论直接嵌在消息卡片内，不改变原有消息流程与布局。

| 结论 | 判定口径（涨跌幅均相对**发行价**，非昨收） |
|---|---|
| **暴涨** | 最新价或上市首日收盘价较发行价 **≥ +100%** |
| **破发** | 最新价较发行价 **≤ −0.5%**（跌破发行价）；**≤ −20%** 另记「深度破发」 |
| **平稳** | 介于两者之间，未触发上述阈值 |
| **未上市** | 尚未到上市日，给出预计上市日与倒计时 |
| **待判定** | 行情或发行价基准缺失，**只陈述走势、不做判定** |

- **首日与上市后区间分别设阈后合并**：以「最新」为主；最新平稳但首日暴涨 / 破发时按首日升级——「曾出现」不漏报，当前状态也不被历史遮蔽（首日 +683% 而后跌破发行价，结论仍为破发）。
- **阈值依据**：+100% 兼顾 A 股主板首日 44% 涨停上限与创业板 / 科创板、港股无涨跌幅限制的现实；−0.5% 为缓冲带，避免四舍五入与除权口径造成的伪破发。
- **发行价三级来源**：新股日历定价（区间定价取中值并在文案中声明）→ 上市前「伪 K 线」收盘价 → 上市首日昨收。
- **兜底不判负面**：未上市、无日线、无发行价、非新股日历标的，一律归入「未上市 / 待判定」，绝不因数据缺失输出看空结论。数据源对未上市标的返回全 0 报价、对上市前一日返回成交量为 0 的「伪 K 线」，两者都已在实现中显式甄别。
- 判定规则详见附录 **B.2.9**，相关术语见 **A.6.9 / A.6.10**；调试接口 `GET /api/ipo/perf?code=xxx`。

## 术语跳转（正文 ↔ 附录）

正文中出现的专业术语会自动标注为**虚线可点击**元素，点击后平滑滚动到附录「术语解释」对应词条并短暂高亮；附录顶部提供**「返回正文」**按钮，可回到原术语位置并闪烁确认。

### 维护方式（单一数据源，无需改动视图代码）

| 要做什么 | 改哪里 |
|---|---|
| 新增 / 修改术语词条 | `lib/appendix.js` 第一部分（A.x.y）的 `no / term / en / meaning / scene` |
| 补充简称、别称、英文缩写 | `lib/terms.js` 的 `EXTRA_ALIASES`（按条目编号登记，如 `'A.2.1': ['PE', '市盈率']`） |
| 匹配规则调整 | `lib/terms.js` 的 `deriveAliases()`（从术语名自动派生）与 `MIN_ALIAS_LEN` |

- 后端 `GET /api/terms` 输出统一索引：`{no, term, en, category, aliases[]}`，前端启动时拉取，**所有视图自动生效**（含异步渲染与页签切换）。
- 索引含 **83 个术语 / 275 个别名**；匹配按**别名长度降序**（"涨跌幅" 优先于 "涨跌"）。
- 同一别名若被多个条目占用会被自动丢弃并记入响应的 `dropped`（保证跳转唯一、无歧义）。

### 可访问性

- 术语链接为原生 `<button>`：可 Tab 聚焦、Enter / Space 触发，带 `aria-label` 与 `title`；`:focus-visible` 有清晰焦点环。
- 跳转后焦点落在「返回正文」按钮，键盘用户可直接回退；返回后焦点回到原术语。
- 尊重 `prefers-reduced-motion`：关闭平滑滚动与闪烁动画。
- 移动端（≤760px）加大点击热区，「返回正文」条改为非吸顶，避免遮挡。
- 输入框、代码块、附录自身词条正文不参与标注；可点击行内的术语会阻止冒泡，不会误触发行跳转。

## 测试

```bash
node tools/verify-data.js http://127.0.0.1:8787   # 178 项数据自洽性校验
node tools/verify-iperf.js <edge路径> <调试端口> http://127.0.0.1:8787   # 25 项暴涨 / 破发判定回归
node tools/qa.js <edge路径> <调试端口> http://127.0.0.1:8787 <截图目录>   # 浏览器全量回归
```

> 提示：`verify-data` 与 `verify-iperf` 依赖实时数据源，首次运行需等待接口冷缓存回源（约 1–3 分钟）。
