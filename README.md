# Finance Hub · 金融信息聚合平台

基于 **Node 原生 http（零 npm 依赖）** 的本地金融信息聚合平台，数据源为 [westock CLI](https://github.com/)（腾讯自选股数据接口），全部为真实数据。浅色商务风单页前端（Chart.js 本地内置），遵循 A 股「涨红跌绿」配色惯例。

## 功能模块

| 模块 | 能力 |
|---|---|
| **市场总览** | 指数行情、13 维市场画像雷达、涨跌分布、行业榜、新股动态 |
| **新股消息** | 沪深 / 港股 / 美股三市场新股日历，阶段自动归类，订阅推送（站内通知中心 + 定时巡检） |
| **新股资讯** | 在发新股相关新闻聚合（标题 / 时间 / 摘要），热度榜，点击查看个股全部资讯 |
| **股票列表** | 7 维分类浏览：宽基指数 / 申万一二级 / 热门概念 / 沪深港通 / 热门榜单 / 港股（模拟数据占位）；点击直达财报 |
| **推荐榜单** | 12 种量化榜单 × 50 只，每只附可溯源推荐理由与风险提示 |
| **AI 选股** | 三档激进度（保守 / 稳健 / 进取）差异化推荐方案；持仓持续判读卖出信号（S1–S7 规则）；自选与交易记录管理；每天 08:30 自动分析 |
| **全球行情** | 贵金属（伦敦金 / 银现货实时价 + 境内 ETF 代理走势）、外汇（10 货币对汇率 / 日 K / 分时 / 波动统计） |
| **国际形势** | 全球市场快照、多源国际要闻聚合、规则化主题影响分析（逐条引用真实新闻标题） |
| **财报整理** | 三大报表结构化归集、多期趋势、多公司对比、披露日历、主营业务与收入结构 |
| **市场分析** | 板块轮动四榜、热搜、市场体检报告一键生成并导出 HTML |
| **附录** | 125 条术语与评分依据（三级编号、可点击互引、深链直达）、港股 / A 股交易指南 |

## 启动

```bat
:: 需要先安装 westock CLI（腾讯自选股数据接口）
启动平台.bat
:: 或
node server.js --port=8787
```

浏览器访问 <http://127.0.0.1:8787>。持仓、交易、通知等用户数据持久化在 `data\`（自动创建，不入库）。

## 目录结构

```
server.js            HTTP 服务与路由（零依赖）
lib/                 westock 数据层 / 分析引擎 / 各模块业务逻辑
public/              单页前端（原生 JS，模块化视图）
tools/               回归测试（qa / verify-data / verify-nav / verify-period / shot）
preview/             各模块界面截图
```

## 测试

```bash
node tools/verify-data.js http://127.0.0.1:8787   # 171 项数据自洽性校验
node tools/qa.js <edge路径> <调试端口> http://127.0.0.1:8787 <截图目录>   # 浏览器全量回归
```
